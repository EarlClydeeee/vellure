## How to capture

1. Run `npm run dev` locally (or use deployed Vercel URL)
2. Use browser DevTools device toolbar for mobile (iPhone 12 / 375px width)
3. Save PNG files to this folder using names like:
   - `01-home-desktop.png`
   - `01-home-mobile.png`
   - `02-products-desktop.png`
   - etc.
